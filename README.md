# Solution Contabilidade e Serviços - Landing Page Institucional

Website institucional e landing page moderna desenvolvida para a **Solution Contabilidade e Serviços**, focada em autoridade contábil, captação de clientes B2B, planejamento tributário e abertura de empresas.

---

## 🌟 Funcionalidades e Diferenciais

- **Design Responsivo de Alta Conversão:** Totalmente otimizado para desktop, tablets e smartphones.
- **Identidade Visual Fiel:** Paleta refinada com Azul Marinho Profundo (`#0A1128`), Dourado/Âmbar (`#F59E0B`) e Branco puro.
- **Tipografia Moderna:** Google Fonts (*Plus Jakarta Sans*).
- **Logotipo Oficial Vetorizado e em Alta Resolução:** Integrado no cabeçalho e no rodapé.
- **Interatividades:**
  - 🟢 **Botão Flutuante do WhatsApp** com status "Consultores Online" e mensagem predefinida.
  - 📋 **Modal de Captação de Leads / Proposta Sob Medida** com validação e notificações toast.
  - ❓ **Acordeão de Dúvidas Frequentes (FAQ)** com animações suaves e acessibilidade via ARIA.
  - 💬 **Carrossel de Depoimentos de Clientes** com controles de paginação.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 Semântico**
- **CSS3 Moderno** (Flexbox, CSS Grid, Custom Properties / CSS Variables)
- **JavaScript Vanilla** (Zero dependências externas pesadas)

---

## 🚀 Como Executar Localmente

1. Clone o repositório:
```bash
git clone https://github.com/gabztoo/solution-contabilidade.git
cd solution-contabilidade
```

2. Abra o arquivo `index.html` em seu navegador ou use qualquer servidor local:
```bash
# Com Python:
python -m http.server 8080

# Ou com Node / npx:
npx serve .
```

3. Acesse no navegador: `http://localhost:8080`
